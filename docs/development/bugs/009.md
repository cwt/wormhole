# BUG-009 — Recursion Stack Overflow on Network Interface Toggles

- **Status**: 🟢 Fixed
- **File**: [`wormhole/proxy.py:L276-288`](../../../wormhole/proxy.py#L276-L288)
- **Severity**: High

## Description
When network monitoring detects IPv6 availability changes under `--auto-ipv6`, `main_async` triggers a server restart by calling `await main_async(args)` recursively inside its `finally` block.

## Impact
Repeated network interface state changes accumulate python call stack frames, eventually crashing the process with `RecursionError`.
