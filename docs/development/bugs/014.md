# BUG-014 — /etc/hosts Multi-IP Overwrite in Host Cache Parsing

- **Status**: 🔴 Open
- **File**: [`wormhole/resolver.py:L117-122`](../../../wormhole/resolver.py#L117-L122)
- **Severity**: Medium

## Description
`self.hosts_cache` maps a hostname string to a single IP address string (`dict[str, str]`). If `/etc/hosts` contains both IPv4 (`127.0.0.1 localhost`) and IPv6 (`::1 localhost`) records, subsequent lines overwrite earlier ones.

## Impact
Dual-stack `/etc/hosts` lookups drop one of the IP address families.
