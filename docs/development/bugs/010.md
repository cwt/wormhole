# BUG-010 — Invalid setsockopt Sequence for Dual-Stack Socket Binding

- **Status**: 🔴 Open
- **File**: [`wormhole/server.py:L209-224`](../../../wormhole/server.py#L209-L224)
- **Severity**: High

## Description
In `start_wormhole_server`, dual-stack socket configuration executes `setsockopt(socket.IPPROTO_IPV6, socket.IPV6_V6ONLY, 0)` *after* `await asyncio.start_server(...)` has already created and bound the socket. On POSIX systems, `IPV6_V6ONLY` must be set prior to binding.

## Impact
Dual-stack binding fails or falls back to single-stack IPv6-only binding.
