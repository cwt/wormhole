# BUG-005 — Lack of Read/Idle Timeouts in Stream Relaying

- **Status**: 🟢 Fixed
- **File**: [`wormhole/handler.py:L42-53`](../../../wormhole/handler.py#L42-L53)
- **Severity**: High

## Description
`relay_stream` executes `await reader.read(4096)` in a loop until EOF. If a client or target server stops transmitting data without closing the socket (half-open TCP connection), the task blocks indefinitely.

## Impact
Stalled or inactive proxy connection tasks linger forever in memory, exhausting socket handles and system resources.
