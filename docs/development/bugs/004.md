# BUG-004 — Connection Stream Socket Leak in Happy Eyeballs Race

- **Status**: 🔴 Open
- **File**: [`wormhole/handler.py:L222-238`](../../../wormhole/handler.py#L222-L238)
- **Severity**: High

## Description
In `_create_fastest_connection`, when one connection task succeeds, pending tasks are cancelled via `p_task.cancel()` and gathered using `await asyncio.gather(*pending, return_exceptions=True)`. If a secondary connection task completes right before or during cancellation, `asyncio.open_connection` returns a valid `(reader, writer)` pair. Because `gather` swallows exceptions/results without checking, secondary socket writers are never closed.

## Impact
Open socket file descriptors leak whenever host resolution returns multiple IP addresses and secondary connection attempts complete during the race.
