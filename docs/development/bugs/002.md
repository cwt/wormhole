# BUG-002 — SSRF Security Bypass via Global DNS Cache Pollution

- **Status**: 🔴 Open
- **File**: [`wormhole/handler.py:L99-109`](../../../wormhole/handler.py#L99-L109)
- **Severity**: Critical

## Description
`_resolve_and_validate_host` checks the global `DNS_CACHE` before performing `is_private_ip()` validation. If a host is resolved during a request with `allow_private=True`, its resolved private IP list is stored in `DNS_CACHE`. A subsequent request for the same hostname with `allow_private=False` hits `DNS_CACHE` first and returns the private IPs without running security checks.

## Impact
Bypasses default private IP security rules, allowing Server-Side Request Forgery (SSRF) against internal network resources.
