# BUG-003 — Unbounded Content-Length Payload Allocation (DoS Risk)

- **Status**: 🔴 Open
- **File**: [`wormhole/handler.py:L660-662`](../../../wormhole/handler.py#L660-L662)
- **Severity**: Critical

## Description
In `parse_request`, `content_length` is extracted directly from HTTP `Content-Length` headers without maximum boundary checks. The handler directly executes `await client_reader.readexactly(content_length)`.

## Impact
A malicious client can send a header like `Content-Length: 2147483648` (2 GB), forcing the server to attempt massive RAM allocations and causing immediate Out-Of-Memory (OOM) crashes.
