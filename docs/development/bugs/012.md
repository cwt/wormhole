# BUG-012 — Permanent lru_cache Prevents Network Interface Tracking

- **Status**: 🟢 Fixed
- **File**: [`wormhole/safeguards.py:L36-37`](../../../wormhole/safeguards.py#L36-L37)
- **Severity**: Medium

## Description
`has_public_ipv6()` is decorated with `@lru_cache(maxsize=1)`. Because it takes zero arguments, the result of the initial IPv6 connectivity lookup is cached permanently for the life of the process.

## Impact
`--auto-ipv6` network monitoring can never register post-boot IPv6 interface updates or routing changes.
