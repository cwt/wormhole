# BUG-017 — Triplicated Parent Domain String Splitting in is_ad_domain

- **Status**: 🟢 Fixed
- **File**: [`wormhole/safeguards.py:L237-259`](../../../wormhole/safeguards.py#L237-L259)
- **Severity**: Low

## Description
`is_ad_domain` splits domain labels (`parts = hostname_lower.split(".")`) and constructs parent domain strings inside 3 separate loops (`BLOCK_LIST_SET`, `AD_BLOCK_SET`, and `ALLOW_LIST_SET`).

## Impact
Unnecessary string allocations and split operations on every proxy request.
