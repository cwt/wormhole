# BUG-008 — LogThrottler Timer Handle Accumulation on Logger Setup

- **Status**: 🟢 Fixed
- **File**: [`wormhole/logger.py:L82-91`](../../../wormhole/logger.py#L82-L91), [`wormhole/logger.py:L157-159`](../../../wormhole/logger.py#L157-L159)
- **Severity**: Medium

## Description
`setup_logger` monkey-patches `LogThrottler.process` onto loguru logger methods. If `setup_logger` is called multiple times, previously scheduled `call_later` timer handles remain active in the event loop without being reset or cancelled.

## Impact
Leaks event loop timer callbacks and causes unexpected delayed log message flushes.
