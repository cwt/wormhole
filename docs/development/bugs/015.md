# BUG-015 — Bracketed IPv6 Host String Regex Parsing Bug

- **Status**: 🔴 Open
- **File**: [`wormhole/tools.py:L4`](../../../wormhole/tools.py#L4), [`wormhole/tools.py:L21-23`](../../../wormhole/tools.py#L21-23)
- **Severity**: Medium

## Description
`REGEX_HOST = re.compile(r"(.+?):([0-9]{1,5})")` fails on standard bracketed IPv6 host strings like `[::1]:8800`. `match.group(1)` matches `"[::1"`, leaving an unclosed leading square bracket.

## Impact
DNS resolution and connection attempts fail when receiving bracketed IPv6 host targets.
