# BUG-001 — Unvalidated Nonces in HTTP Digest Authentication (Replay Attack)

- **Status**: 🟢 Fixed
- **File**: [`wormhole/authentication.py:L93-102`](../../../wormhole/authentication.py#L93-L102), [`wormhole/authentication.py:L166-174`](../../../wormhole/authentication.py#L166-L174)
- **Severity**: Critical

## Description
In `send_auth_required_response`, the proxy generates a cryptographically random `nonce` and `opaque` token. However, these tokens are never stored or tracked in server state. When a client responds with credentials, `verify_credentials` accepts whatever `nonce`, `nc`, and `cnonce` parameters the client sends and computes the digest against them.

## Impact
An attacker can capture valid `Proxy-Authorization` headers and replay them indefinitely against the proxy to bypass challenge-response authentication.
