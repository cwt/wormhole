# BUG-011 — Zero-Index Assignment Evaluation Bug in relay_stream

- **Status**: 🔴 Open
- **File**: [`wormhole/handler.py:L49-50`](../../../wormhole/handler.py#L49-L50)
- **Severity**: Medium

## Description
In `relay_stream`, `if end_of_line := data.find(b"\r\n"):` evaluates to `False` when `\r\n` is located at byte index 0 of the chunk, because `0` is falsy in Python boolean evaluation.

## Impact
`first_line` remains `None` when `\r\n` occurs at index 0 of a stream chunk, missing the response status line.
