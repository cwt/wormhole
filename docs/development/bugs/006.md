# BUG-006 — Unbounded Growth of Global DNS Cache Dictionary

- **Status**: 🔴 Open
- **File**: [`wormhole/handler.py:L12-14`](../../../wormhole/handler.py#L12-L14)
- **Severity**: Medium

## Description
`DNS_CACHE` is defined as a global dictionary without maximum capacity constraints, LRU eviction logic, or background TTL cleanup tasks.

## Impact
Long-running proxy instances handling millions of unique domain requests experience steadily increasing memory usage.
