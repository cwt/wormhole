# BUG-018 — EasyList Regular Expression Mis-match and Ingestion Bug

- **Status**: 🟢 Fixed
- **File**: [`wormhole/ad_blocker.py:L20-24`](../../../wormhole/ad_blocker.py#L20-L24), [`wormhole/ad_blocker.py:L86-95`](../../../wormhole/ad_blocker.py#L86-L95)
- **Severity**: Low

## Description
`DOMAIN_REGEX` only matches exact `||example.com^` rules and ignores rules with options (e.g. `||example.com^$third-party`). The fallback branch `elif "." in line and " " not in line:` then ingests strings like `"||example.com^$third-party"` into the blocklist set verbatim.

## Impact
Pollutes the ad-block SQLite database with unparseable domain strings that never match actual web host requests.
