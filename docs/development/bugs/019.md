# BUG-019 — Unenforced Concurrency Limit (MAX_TASKS)

- **Status**: 🔴 Open
- **File**: [`wormhole/server.py:L13-26`](../../../wormhole/server.py#L13-L26), [`wormhole/server.py:L59-67`](../../../wormhole/server.py#L59-L67)
- **Severity**: Low

## Description
`MAX_TASKS` is calculated based on OS file descriptor limits (`RLIMIT_NOFILE`). However, `handle_connection` only logs `CURRENT_TASKS/MAX_TASKS` in debug mode without rejecting connections or closing streams when limits are exceeded.

## Impact
High connection bursts can exceed OS file limits and crash with `EMFILE` / `Too many open files` errors.
