# BUG-016 — Subdomain Optimization Complexity in Ad-Block Compiler

- **Status**: 🟢 Fixed
- **File**: [`wormhole/ad_blocker.py:L113-126`](../../../wormhole/ad_blocker.py#L113-L126)
- **Severity**: Low

## Description
`_filter_redundant_domains` sorts ~500,000 domains in reverse order of length and iterates through them against a full initial domain set. For every domain, it splits labels and constructs parent domain strings.

## Impact
Significant CPU overhead during `--update-ad-block-db` operations. Processing shortest domains first allows building an optimized set without redundant lookups.
