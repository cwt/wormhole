# BUG-007 — Stale Event Loop Reference in Singleton Resolver

- **Status**: 🔴 Open
- **File**: [`wormhole/resolver.py:L33`](../../../wormhole/resolver.py#L33), [`wormhole/resolver.py:L160-162`](../../../wormhole/resolver.py#L160-L162)
- **Severity**: High

## Description
`Resolver` is implemented as a singleton. Its internal `aiodns.DNSResolver` is lazily created and bound to `asyncio.get_running_loop()`. If the event loop is closed and re-created (e.g. during `--auto-ipv6` server restarts or unit test teardowns), `self.resolver` retains a reference to the old closed loop.

## Impact
Subsequent DNS resolution requests fail with `RuntimeError: Event loop is closed`.
