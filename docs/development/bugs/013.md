# BUG-013 — Global Auth File Cache Invalidation Bug

- **Status**: 🟢 Fixed
- **File**: [`wormhole/authentication.py:L11-13`](../../../wormhole/authentication.py#L11-L13), [`wormhole/authentication.py:L48-64`](../../../wormhole/authentication.py#L48-64)
- **Severity**: Medium

## Description
`_load_auth_file` uses global state variables (`_auth_file_cache`, `_auth_file_mtime`). If the path argument changes or if the auth file is deleted and re-created with identical mtime, stale credentials from the previous file are returned.

## Impact
Auth file re-configuration or multi-tenant configuration loads stale user credentials.
